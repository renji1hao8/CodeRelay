# 网络入口参考

可信 Wi-Fi 可用 LAN 模式。需要外网访问时，把后端保留在环回地址，通过 HTTPS 或私有网络连接。不要把后端或桌面调试端口直接暴露到公网。

`Caddyfile.example` 演示 HTTPS 反向代理，需换成自己的域名并按 Caddy 文档配置 DNS 和证书。它阻止外部访问本机配对码签发及管理员请求入口。WebSocket 由反向代理转发。

`frpc.example.toml` 是可选隧道结构参考。先通过私密渠道配置自己的隧道服务与鉴权，再把本地服务接到受 HTTPS 保护的入口；示例不能直接作为公网安全部署。凭据放在电脑之外的私密配置，不提交到本仓库。

启用代理访问日志时过滤查询参数 token。不要将实际隧道配置、证书私钥和完整日志附在公开 Issue 中。

没有域名但有公网 IP 时，见 [Let’s Encrypt IP 证书](IP-CERTIFICATE.md)。
