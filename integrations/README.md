# 可选集成

这些目录从原项目的个人工作流整理而来，只保留通用配置和参考代码。实际地址、路径、账号、证书及凭据由使用者在本机填写。

| 集成 | 用途 |
| --- | --- |
| [personal-stack](personal-stack/README.md) | 代理、cc-switch 与文件目录组合配置 |
| [network](network/README.md) | HTTPS 反向代理和隧道参考 |
| [build](build/README.md) | 本地镜像与自签 CA 构建 |
| [startup](startup/README.md) | 登录自动启动和看门狗 |
| [privileged-tools](privileged-tools/README.md) | WebDAV、管理员执行器及旧 CLI |
| [mail-archive](mail-archive/README.md) | 手动把结果归档到手机可见目录 |
| [network-share](network-share/README.md) | 以当前 Windows 用户挂载网络共享 |

集成只读取电脑所有者维护的本地配置，不提供手机上传脚本或安装插件的接口。默认安装不会启动代理、修改系统任务、挂载共享或安装管理员执行器。
