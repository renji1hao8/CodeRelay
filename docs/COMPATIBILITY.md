# 兼容性与验证

首版目标为 Windows 11 与 Android。桌面适配依据当前安装环境中的 Claude 4.29.0 和 Codex 26.1027.3384.0；内置传输快照版本与哈希记录在 `server/vendor/desktop-bridge/UPSTREAM.json`。

已验证的范围：

- 真实本机 Codex 历史分页、附件还原、投递记录确认和消息顺序。
- PowerShell 真实进程的目录/变量保留、交互输入、Tab、历史方向键、Ctrl+C、尺寸变化、断线重连和资源回收。
- 隔离用例的桌面审批、中断、后台任务归属、失效状态、并发投递去重和 Claude 原生恢复身份。
- 设备鉴权、受限默认目录、LAN 模式的本机专用入口，以及可选功能默认关闭。
- 干净源码导出的依赖安装、回归检查与两端类型检查；Windows 便携包在新目录中的向导、启动、配对及终端操作。

依赖审计结果与构建依赖固定版本的原因见 [依赖审计记录](DEPENDENCY-AUDIT.md)。

以下情况需要实机验收，不能把模拟用例当作已验证：

- 不同品牌 Android 手机的输入法、键盘布局、相册选择和压缩预览。
- 当前桌面版本实际执行原生审批、历史唤醒及逐片段输出。连接未开启时只同步已落盘片段。
- 其他 Claude/Codex 桌面版本。控制连接之前已挂起的 Codex 审批不会补采集，需在电脑处理。

Codex 控制层收集命令、文件修改、应用访问与额外权限请求。已适配的 Computer Use 应用访问可在手机允许本次操作，不写入永久授权；身份验证、需要填写内容的表单和未适配的额外权限只显示电脑处理提示，可在手机拒绝。控制连接必须在请求发出前开启，已超时的请求不能恢复。

后台同步受手机系统休眠策略影响。桌面升级更改内部接口时，适配可能暂时不可用；程序应给出错误并保留草稿，不能为了继续而创建替代 CLI 会话。

Claude 手机续接使用桌面原会话的 `LocalSessions.sendMessage`，空闲和运行中的会话都通过同一输入接口提交。桥接插件的跨会话收件箱没有模型接收回执，不能作为空闲会话的启动入口，也不作为发送失败后的回退路径。电脑需用“claude 手机控制”快捷方式开启本机控制连接；接口提交后，手机仍需看到原会话中的用户消息才确认收到。

这项空闲发送修复已增加隔离用例，覆盖桌面注册表绑定、历史 UUID、目录核对和未送达拒绝；真实桌面空闲发送与手机端仍需实机验收。
